# Pineapple Time Generator v2 — Design Spec

**Date:** 2026-05-24  
**Updated:** 2026-05-24 (gaps resolved ×4)  
**Status:** Approved

---

## Purpose

Single-purpose tool: create SpongeBob-style time card title cards, customize them, and export as PNG. Nothing more. Open source GPL-3.0.

Two user types:
- **Explorer** — opens app, browses backgrounds and phrases, downloads
- **Power user** — arrives with text in mind, uses favorites for recurring designs

---

## Architecture

```
index.html        ← markup only, no inline CSS or JS
style.css         ← all CSS
app.js            ← all JS, organized in clear sections
backgrounds/      ← preset images (unchanged from v1)
docs/             ← documentation
```

No build step. Works with `file://`, GitHub Pages, any static server. Clone and open — done.

`app.js` internal organization (sections, not separate files):
- `// --- Data ---` (phrases array, backgroundPresets array)
- `// --- Utils ---` (clamp, roundOneDecimal, toast, brightness helpers)
- `// --- State ---` (state object + `setState` function)
- `// --- Render ---` (functions that read state and update DOM)
- `// --- Events ---` (all event listeners, at bottom in DOMContentLoaded)
- `// --- Init ---` (initial state setup)

## State

Single JS object, source of truth. DOM is always derived from state, never the other way.

```js
const state = {
  text: '',
  backgroundIndex: 0,         // index into allBackgrounds() — see below
  customBackgrounds: [],       // base64 URLs from upload, prepended to presets; max 5; persisted
  fontSize: 3,                 // em — range [0.5, 8], step 0.1; card base font-size is 16px so 3em = 48px
  textColor: '#3e1600',
  shadowColor: '#ffeb99',
  positionX: 50,               // 5-95 (50 = center; clamped to safe area)
  positionY: 50,               // 5-95 (50 = center; clamped to safe area)
  textAlign: 'center',         // 'left' | 'center' | 'right'
  ratio: '16:9',               // '16:9' | '4:3'
  advancedOpen: false,         // persisted in localStorage key pineapple_v2_ui
};
```

### setState

**No event handler mutates `state` directly.** All mutations go through:

```js
function setState(patch) {
  Object.assign(state, patch);
  render();
}
```

**Exception — Init:** `Init` mutates `state` directly with `Object.assign` and calls `render()` once at the end. This avoids multiple redundant renders during startup. The setState rule applies only to event handlers and async callbacks.

`render()` reads state and updates DOM. No function reads back from DOM to get state.

## Backgrounds Array

```js
// Computed, never stored in state
function allBackgrounds() {
  return [
    ...state.customBackgrounds.map((url, i) => ({
      url,
      isCustom: true,
      label: `Fondo personalizado ${i + 1}`
    })),
    ...backgroundPresets
  ];
}
```

### backgroundPresets structure

```js
// Each entry:
{ url: String, label: String }
// Example:
{ url: 'backgrounds/krusty-krab.jpg', label: 'Krusty Krab' }
```

`label` is used for `aria-label` on thumbnails and `title` tooltip. Custom backgrounds generate their label dynamically from position index.

### Custom backgrounds

- `state.backgroundIndex` indexes into `allBackgrounds()`. Custom uploads prepend.
- **On new upload:** prepend to `customBackgrounds`, set `backgroundIndex: 0` (auto-selects). If adding would exceed 5, drop the oldest entry (`customBackgrounds.pop()`) and show toast "Fondo más antiguo eliminado para hacer espacio".
- **Persisted** in `localStorage` key `pineapple_v2_custom_bgs` (array of base64 URLs, max 5 ≈1.5MB total).
- On page load, `customBackgrounds` is restored from `localStorage` before first render.

## Components

### Card Preview

- Full-width div, `max-width: 900px`, centered. At scale:2 export: max 1800px PNG.
- `font-size: 16px` set explicitly on the card element — all `em` values for text are relative to this
- Aspect ratio set via CSS `aspect-ratio` property (`16/9` or `4/3`)
- `position: relative; overflow: hidden`
- Text lives in a `.text-wrapper` child, always present (initialized in `render()`)
- **`.text-wrapper` CSS:** `position: absolute`, `width: 90%`, `left: {positionX}%`, `top: {positionY}%`, `transform: translate(-50%, -50%)`. Fixed width of 90% gives `textAlign` room to be visible. Anchor point is the center of the wrapper.
- **Text rendering:** `white-space: pre-wrap; overflow-wrap: break-word; text-align: {textAlign}`
- **Text shadow:** `2px 2px 0 ${shadowColor}, -2px -2px 0 ${shadowColor}`
- **Drag safe area:** X and Y clamped to `[5, 95]`. Prevents text from being clipped by `overflow: hidden` at card edges.
- **Mouse drag:**
  - `mousedown` on card → begin drag, apply `user-select: none` to card
  - Track `mousemove` on `document` → `deltaX / card.offsetWidth * 100`
  - `mouseup` on `document` → end drag, restore `user-select`
- **Touch drag:** `touchstart` / `touchmove` / `touchend` with `{ passive: false }`. `touchmove` calls `e.preventDefault()` to block page scroll. Only `touches[0]` tracked; multi-touch ignored.
- `render()` updates text wrapper content and position — never replaces the element

### Background Strip

- Horizontal scroll container
- One thumbnail per background (custom first, then presets). `aria-label` and `title` from `label`.
- Visual separator between custom and preset sections when custom backgrounds exist.
- Active thumbnail highlighted.
- Custom thumbnails show a remove button (✕) — removes from `state.customBackgrounds`, reindexes `backgroundIndex` (if active was removed, select next available or first preset). Uses `setState`.
- Upload button (`+`) at the end — triggers `<input type="file" accept="image/*">`.
- Clicking a thumbnail → `setState({ backgroundIndex })` → calls `autoAdjustColors()`.
- **Strip rebuilt only when `customBackgrounds.length` or `backgroundIndex` changes** — text/position/color updates do not trigger strip rebuild (prevents scroll reset on keypress).
- **After rebuild:** call `activeThumb.scrollIntoView({ behavior: 'smooth', block: 'nearest', inline: 'center' })` to keep active thumbnail visible.

### Text Row

- **Input:** `<textarea>` (single visible row, resize disabled). Newlines preserved.
- `render()` does **not** update `textarea.value` if `document.activeElement === textarea` — prevents cursor jumping while typing. Updates value only when focus is elsewhere.
- Random phrase button (↺) — picks random from `phrases[]`, **excluding the current phrase**. Updates state, renders.
- Download button (↓) — triggers html2canvas export; **disabled while export is in progress**.

### Advanced Panel

- Toggle button shows/hides panel; `state.advancedOpen` persisted in `localStorage` key `pineapple_v2_ui`.
- **Escape key closes panel** if open (import modal consumes Escape first when visible).
- All sections always visible when panel is open (no nested collapse).
- **Colors:** text color picker (`<input type="color">`), shadow color picker (`<input type="color">`), Random Colors button.
- **Size:** font size slider (min 0.5, max 8, step 0.1) + +/- buttons (values rounded to 1 decimal).
- **Position:** X slider (5–95), Y slider (5–95), align L/C/R buttons, Reset button (resets to `positionX: 50`, `positionY: 50`, `textAlign: 'center'`).
- **Ratio:** 16:9 / 4:3 toggle button.
- **Favorites:** save (name input + save button), list (load/delete per item), export JSON, import JSON.
- **Keyboard shortcut:** Ctrl+S calls `e.preventDefault()`, opens advanced panel via `setState`, scrolls to Favorites section, focuses the name input.

## Favorites

Stored in `localStorage` under key `pineapple_v2_favorites`.

**v1 migration:** v1 key not read automatically. Users export from v1 and import into v2.

### Structure

```js
{
  id: Number,          // Date.now()
  name: String,        // duplicates allowed; empty name blocked at save
  text: String,
  backgroundUrl: String,
  fontSize: Number,
  textColor: String,
  shadowColor: String,
  positionX: Number,
  positionY: Number,
  textAlign: String,
  ratio: String,
}
```

**List order:** newest first (most recently saved at top).

**Save:** name input must be non-empty — if empty, show inline message "Escribe un nombre" and abort. Wrap `localStorage.setItem` in try/catch for `QuotaExceededError`, show toast on failure.

**Delete:** soft delete with undo. On click, remove from list immediately. Show toast "Favorito eliminado [Deshacer]" for 5 seconds. Undo toasts are **exempt from the single-toast rule** — they stack up to 3 simultaneously, each with its own independent 5s timer. Clicking Deshacer re-inserts the favorite at its original position. After 5s without undo, deletion is permanent.

**Load:** restores full state from favorite. If `backgroundUrl` matches a preset `url`, sets `backgroundIndex` to that preset. Otherwise re-inserts into `state.customBackgrounds` (if not already present, subject to max-5 eviction) and sets `backgroundIndex` to its position. Calls `setState`.

### Export

Downloads `pineapple-favorites.json` with versioned wrapper:
```json
{ "version": 2, "favorites": [ ... ] }
```

### Import modal

Closing overlay or pressing Escape cancels with no action. Merge and Replace are explicit button choices only.
- Not valid JSON → toast "Archivo no válido"
- Valid JSON, missing `version` field or `favorites` array → toast "Formato no reconocido"
- Entries missing required fields → skipped. Toast: "3 favoritos importados" or "3 importados, 1 omitido"
- **Merge deduplication:** entries whose `id` already exists in the current list are skipped silently.

## Color System

### Brightness

```js
// Standard luminance weights
function colorBrightness(hex) {
  const r = parseInt(hex.slice(1,3), 16);
  const g = parseInt(hex.slice(3,5), 16);
  const b = parseInt(hex.slice(5,7), 16);
  return 0.299 * r + 0.587 * g + 0.114 * b;
}
```

### Curated palettes

```js
// SpongeBob-themed; intentionally limited for visual coherence
const DARK_PALETTE  = ['#3e1600', '#1a0a00', '#0d1b2a', '#1b2a1b', '#2a0a2a'];
const LIGHT_PALETTE = ['#ffeb99', '#ffe566', '#fff4cc', '#ffd700', '#fff8e1'];

function generateDarkColor()  { return DARK_PALETTE[Math.floor(Math.random() * DARK_PALETTE.length)]; }
function generateLightColor() { return LIGHT_PALETTE[Math.floor(Math.random() * LIGHT_PALETTE.length)]; }
```

### autoAdjustColors

```js
async function autoAdjustColors(url) { ... }
```

- Loads image into offscreen canvas (100×100px)
- Computes brightness with formula above
- If brightness < 128: `generateLightColor()` for text + `generateDarkColor()` for shadow
- If brightness >= 128: `generateDarkColor()` for text + `generateLightColor()` for shadow
- Falls back to brightness 128 on CORS/taint errors
- Result cached in `Map<url, brightness>` — same URL never analyzed twice
- **Race condition guard:** captures `url` at call start; before calling `setState`, checks `allBackgrounds()[state.backgroundIndex].url === url`. If mismatch, discards result silently.

**Async / render flow:** `setState` applies current colors immediately. `autoAdjustColors` updates colors via `setState` when resolved. Brief color flash on background change is acceptable.

**Random Colors button:** reads cached brightness for current background URL (falls back to 128 if not cached). Applies same palette logic. Always contrast-safe.

## Export

html2canvas on the card element:
- `onclone` removes `.download-overlay` before capture
- `scale: 2` — 2x resolution; card `max-width: 900px` caps output at 1800px wide
- `useCORS: true` — enables CORS for hosted images
- **Download mechanism:** `canvas.toBlob()` + `URL.createObjectURL` + programmatic `<a>` click — non-blocking, handles large images without freezing UI
- Filename: `pineapple-time-card-16-9.png` or `pineapple-time-card-4-3.png`
- Overlay content: spinner + text "Generando..."
- Download button disabled while overlay active; both restored on done/error

### file:// limitation

Preset background images (relative paths) may render blank in exported PNG when using `file://` protocol due to browser security restrictions. Custom uploaded backgrounds (base64 data URLs) always export correctly regardless of protocol. Recommended: serve via GitHub Pages or a local server (`python -m http.server`) for reliable preset export.

## Init

Init mutates `state` directly (bypasses `setState`) and calls `render()` once at the end. This avoids multiple redundant renders during startup.

```
1. Read pineapple_v2_ui      → state.advancedOpen    (try/catch, fallback: false)
2. Read pineapple_v2_custom_bgs → state.customBackgrounds (try/catch, fallback: [])
3. Read pineapple_v2_favorites  → favorites list      (try/catch, fallback: [])
4. Pick random phrase (excluding none on first load) → state.text
5. Pick random backgroundIndex → state.backgroundIndex
6. Object.assign(state, { text, backgroundIndex, advancedOpen, customBackgrounds })
7. render()
8. autoAdjustColors(currentUrl) → setState when resolved
```

All three `localStorage` reads are individually wrapped in try/catch. Corrupted or unparseable data is silently discarded in favor of the default value.

---

## Toasts

- Duration: **3 seconds**, then fade out
- Stacking rule: new toast replaces the current visible toast — **except undo toasts**, which stack up to 3 simultaneously with independent timers
- Used for: save success, save failure (quota), delete undo, custom bg eviction, import result, export error, invalid file

## Bug Fixes vs v1

| Bug | Fix |
|-----|-----|
| `updateText` destroys `.text-wrapper` | Render updates wrapper content and position, never replaces element |
| Random bg on load has wrong colors | Init calls `autoAdjustColors()` after first render |
| Import modal: overlay triggers Replace | Overlay close = cancel only; Replace requires explicit button click |
| No touch drag | `touchstart/move/end` with `{ passive: false }`, `preventDefault()` on move |
| `localStorage` throws on quota exceeded | Wrap all setItem calls in try/catch; toast on failure |
| Float drift in font size buttons | `Math.round(value * 10) / 10` after each increment |
| autoAdjustColors race condition | URL guard before applying async result |
| Random Colors picks ugly arbitrary colors | Curated SpongeBob-themed palettes |
| Accidental favorite delete with no recovery | Soft delete with 5s undo toast |
| Init triggers multiple renders | Init mutates state directly, single render() at end |
| Typing resets textarea cursor | render() skips textarea.value when textarea has focus |
| textAlign has no visual effect | .text-wrapper fixed at width: 90% |
| Active thumbnail lost after strip rebuild | scrollIntoView after rebuild |
| Corrupted localStorage crashes on load | All init reads wrapped in try/catch with fallback |
| Text clipped at card edges | Drag clamped to safe area [5, 95] |
| Mouse drag selects page text | user-select: none during mousedown/mouseup |
| Import merge creates duplicates | Merge deduplicates by id |
