# Pineapple Time Generator v2 — Design Spec

**Date:** 2026-05-24  
**Status:** Approved

---

## Purpose

Single-purpose tool: create SpongeBob-style time card title cards, customize them, and export as PNG. Nothing more. Open source GPL-3.0.

Two user types:
- **Explorer** — opens app, browses backgrounds and phrases, downloads
- **Power user** — arrives with text in mind, uses favorites for recurring designs

---

## Architecture

```
index.html        ← markup only, no inline CSS or JS
style.css         ← all CSS
app.js            ← all JS, organized in clear sections
backgrounds/      ← preset images (unchanged from v1)
docs/             ← documentation
```

No build step. Works with `file://`, GitHub Pages, any static server. Clone and open — done.

`app.js` internal organization (sections, not separate files):
- `// --- Data ---` (phrases array, backgroundPresets array)
- `// --- State ---` (single state object, no DOM-as-state)
- `// --- Render ---` (functions that read state and update DOM)
- `// --- Events ---` (all event listeners, at bottom in DOMContentLoaded)
- `// --- Init ---` (initial state setup)

---

## Layout

Vertical progressive. Mobile-first, desktop-primary.

```
┌─────────────────────────────────┐
│  Pineapple Time Generator       │  ← header, minimal
├─────────────────────────────────┤
│                                 │
│         CARD PREVIEW            │  ← full width, 16:9 or 4:3
│    (text draggable via mouse    │
│     and touch)                  │
│                                 │
├─────────────────────────────────┤
│ [bg][bg][bg][bg][bg][bg]... [+] │  ← horizontal scroll, upload at end
├─────────────────────────────────┤
│ [     text input     ] [↺] [↓]  │  ← input + random phrase + download
├─────────────────────────────────┤
│ ▼  Personalizar                 │  ← collapsible, closed by default
│   [colors] [size] [position]    │
│   [ratio]  [favorites]          │
└─────────────────────────────────┘
```

- Download button always visible — never buried
- Backgrounds strip always visible — core exploration action
- Text input always visible — direct user can type immediately
- Advanced panel collapsed by default — doesn't intimidate casual users

## State

Single JS object, source of truth. DOM is always derived from state, never the other way.

```js
const state = {
  text: '',
  backgroundIndex: 0,         // index into allBackgrounds() — see below
  customBackgrounds: [],       // base64 URLs from upload, prepended to presets
  fontSize: 3,                 // em
  textColor: '#3e1600',
  shadowColor: '#ffeb99',
  positionX: 50,               // 0-100
  positionY: 50,               // 0-100
  textAlign: 'center',         // 'left' | 'center' | 'right'
  ratio: '16:9',               // '16:9' | '4:3'
  advancedOpen: false,
};
```

`render()` reads state and updates DOM. No function reads back from DOM to get state.

---

## Backgrounds Array

```js
// Computed, never stored in state
function allBackgrounds() {
  return [
    ...state.customBackgrounds.map(url => ({ url, isCustom: true })),
    ...backgroundPresets
  ];
}
```

`state.backgroundIndex` indexes into `allBackgrounds()`. Custom uploads prepend, so index 0 is always the most recently uploaded.

## Components

### Card Preview
- Full-width div with background-image and overlay text
- Text lives in a `.text-wrapper` child, always present (initialized in `render()`)
- Position applied via CSS `transform: translate(x%, y%)`
- Drag: mouse events + touch events (touchstart/touchmove/touchend)
- `render()` updates text wrapper content — never replaces it

### Background Strip
- Horizontal scroll container
- One thumbnail per background (presets + custom uploads)
- Active thumbnail highlighted
- Upload button (`+`) at the end — triggers file input
- Clicking a thumbnail → updates `state.backgroundIndex` → calls `render()` → calls `autoAdjustColors()`

### Text Row
- Text input synced to `state.text`
- Random phrase button (↺) — picks random from phrases[], updates state, renders
- Download button (↓) — triggers html2canvas export

### Advanced Panel
- Toggle button shows/hides panel (`state.advancedOpen`)
- **Colors:** text color picker, shadow color picker, Random Colors button
- **Size:** font size slider + +/- buttons (values rounded to 1 decimal)
- **Position:** X slider, Y slider, align L/C/R buttons, Reset button
- **Ratio:** 16:9 / 4:3 toggle button
- **Favorites:** save (name input + button), list (load/delete per item), export JSON, import JSON

## Favorites

Stored in `localStorage` under key `pineapple_v2_favorites`.

Structure per favorite:
```js
{
  id: Number,          // Date.now()
  name: String,
  text: String,
  backgroundUrl: String,
  fontSize: Number,
  textColor: String,
  shadowColor: String,
  positionX: Number,
  positionY: Number,
  textAlign: String,
  ratio: String,
}
```

Save: always wraps `localStorage.setItem` in try/catch for `QuotaExceededError`.  
Load: restores full state from favorite object, calls `render()`.  
Import modal: closing overlay or pressing Escape cancels with no action. Merge and Replace are explicit button choices only.

---

## Color System

`autoAdjustColors(url)`:
- Loads image into offscreen canvas (100×100px)
- Computes average brightness (weighted RGB)
- If brightness < 128: picks random light text + random dark shadow
- If brightness >= 128: picks random dark text + random light shadow
- Falls back to brightness 128 on CORS/taint errors
- Result cached in `Map<url, brightness>` — same URL never analyzed twice

---

## Export

html2canvas on the card element:
- `onclone` removes `.download-overlay` before capture
- Filename: `pineapple-time-card-16-9.png` or `pineapple-time-card-4-3.png`
- Overlay shown during generation, auto-removed on done/error

## Bug Fixes vs v1

| Bug | Fix |
|-----|-----|
| `updateText` destroys `.text-wrapper` | Render updates wrapper's textContent, never replaces it |
| Random bg on load has wrong colors | Init calls `autoAdjustColors()` on the random background |
| Import modal: overlay triggers Replace | Overlay close = cancel only; Replace requires explicit button click |
| No touch drag | Add touchstart/touchmove/touchend handlers |
| `localStorage` throws on quota exceeded | Wrap all setItem calls in try/catch |
| Float drift in font size buttons | `Math.round(value * 10) / 10` after each increment |

## Out of Scope (v2)

- Animations
- GIF / video export
- Batch processing
- Templates library
- Custom fonts

## Technical Constraints

- No frameworks, no npm dependencies in runtime
- Vanilla JS (ES2020+, no modules — file:// compatibility)
- html2canvas via CDN (existing)
- "Some Time Later" font via CDN (existing)
- SRI hashes on CDN scripts
- GPL-3.0 license
